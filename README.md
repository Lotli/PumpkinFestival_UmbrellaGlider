# Umbrella Glider

Too tired of you not being able to float like a real ghost? Introducing "Just A regular umbrella 3000"! Just press "G" to open it and glide or configure your keybind using [Mod Configurator](https://github.com/Lotli/PumpkinFestival_ModConfigurator).

## Set up
### Melon Loader
Recommended [melon loader](https://github.com/LavaGang/MelonLoader) version: v0.7.3\
Other versions will not work cus of the changes in unity v6000.3.\
Download the [latest version of the mod](https://github.com/Lotli/PumpkinFestival_UmbrellaGlider/releases/latest) and put it in the Mods folder.
